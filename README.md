## 🤖 Chatbot Básico

Este repositorio ahora incluye un **chatbot básico** diseñado para usar pocos recursos del sistema.

### Características principales:
- ✅ **Ligero**: Solo usa la biblioteca estándar de Python
- ✅ **Eficiente**: Consume menos de 10MB de RAM
- ✅ **Fácil de usar**: Interfaz simple por línea de comandos  
- ✅ **Sin dependencias**: No requiere instalaciones adicionales

### Uso rápido:
```bash
python3 chatbot.py
```
